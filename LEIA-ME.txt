CONTROLE DE ENTREGAS

Site estático (PWA) hospedado no Vercel, ligado ao repositório do GitHub.
Cada push na branch main dispara um deploy automático. Não há etapa de build.

No ar em: https://controle-entregas-weld.vercel.app


COMO USAR (o que o usuário vê)

- Botões verde/vermelho embaixo: lançar Entrada (ganho) ou Saída (gasto).
- Tocar num lançamento da lista: EDITA aquele lançamento.
- Tocar na lixeira: exclui, e aparece "Desfazer" por alguns segundos.
- Engrenagem no topo: meta de ganho por dia. Só isso.
- Aba "Mês": total do mês, dias trabalhados, e de onde veio / onde foi o dinheiro.

Nada de backup, exportar arquivo ou botão de sincronizar. O app guarda tudo no
servidor sozinho, sem pedir nada e sem mostrar nada.


COMO OS DADOS FICAM SEGUROS

Os lançamentos são salvos no celular (funciona sem internet) e sobem sozinhos
para o Supabase quando há sinal. Sem internet, ficam numa fila e sobem depois.
Ninguém precisa apertar nada.

Na primeira vez que o app abre numa versão nova, ele cria sozinho uma conta
anônima para aquele aparelho e sobe todo o histórico que já estava no celular.


CONFIGURAÇÃO DO SERVIDOR (já feita, registro para referência)

1. Supabase > SQL Editor: rodar o supabase-schema.sql (tabelas + RLS).
2. Supabase > Authentication > Sign In / Providers: ligar "Anonymous sign-ins"
   e clicar em Save.

Sem esses dois passos o app funciona normalmente, mas não guarda no servidor.


COMO VER OS NÚMEROS DE LONGE

Cada aparelho é uma conta anônima própria, então o app no seu celular não mostra
os dados do celular do seu pai. Para ver os números dele:

  Supabase > Table Editor > dispositivos   (descubra o user_id do aparelho)
  Supabase > SQL Editor                    (consultas prontas comentadas no fim
                                            do supabase-schema.sql)

Monitoramento: a coluna "visto_em" da tabela dispositivos só avança quando a
sincronização funciona. Se ela parar de avançar, algo travou.

Atenção: um celular novo cria uma conta nova e vazia. Os dados antigos continuam
no servidor, mas hoje só dá para chegar neles pelo painel do Supabase.
